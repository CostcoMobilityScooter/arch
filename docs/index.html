// WHAT IT DOES

Everything you need.
Nothing you don't.

⚡
App Launcher
Auto-detects 50+ installed apps. Fuzzy search, favorites, aliases. Launch anything in under a second.
📊
System Monitor
Live CPU, RAM, disk, and network stats. Battery status, process viewer, real-time graphs.
🤖
AI Assistant
Powered by Gemini. Ask questions, translate, define words, summarize pages — right in the terminal.
🎨
Fully Themeable
8 built-in themes: green, amber, blue, matrix, red, cyan, purple, white. Create your own with hex codes.
🔒
Security
Password lock screen, encrypted secret vault, recovery key support.
⏱
Productivity
Timers, reminders, Pomodoro, stopwatch, notes, todos, clipboard history, sticky notes.
🌐
Network Tools
Ping, DNS lookup, port scan, speed test, traceroute, HTTP headers, IP lookup.
🗂
File Tools
Browse directories, find duplicates, calculate sizes, diff files, zip/unzip, preview text.
⚙️
Automation
Macro recording, cron job scheduling, command chaining with &&, custom aliases and scripts.
